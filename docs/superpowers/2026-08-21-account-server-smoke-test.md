# 合并前人工冒烟清单 — 账号租约服务

`src/main.js` 是 Electron 主进程接线层,测试套件永远不会加载它,所以下面这些
只能人工过。macOS 下用 `npm start` 跑源码版本。

按顺序做,第 1 条挂了就别往下走。

1. **回归基线(最重要)**
   确认没有 `server-config.json`、没有 `cached-account.json`,启动应用。
   预期:桌面池账号自动登录、加载遮罩正常、标题是「老猫」、菜单和脚本目录正常、
   关掉再开窗口位置被记住 —— 全部与接入这个功能之前一模一样。

2. **空池**
   桌面池里只剩模板账号。预期:窗口照常打开、没有遮罩、不自动登录。
   这是正常状态,不是错误。

3. **远端主路径**(需要真实 Worker + token + 后台已录入账号)
   写好 `server-config.json`。预期:自动登录成功;后台能看到该账号有活跃租约;
   `cached-account.json` 已生成且内容正确。

4. **退出释放**
   `Cmd+Q`。预期:秒退;后台确认账号立即回到可用池;再启动能重新拿到租约。

5. **释放失败也能退**
   运行中断网,然后 `Cmd+Q`。预期:最多约 3 秒后退出,不挂死。

6. **断网回落缓存**
   保留 config、断网、缓存存在。预期:用缓存里的账号登录;`Cmd+Q` 立即退出。

7. **断网且无缓存 → 桌面池**
   删掉缓存,桌面池放真实账号。预期:回落到桌面池登录。

8. **apiBase 填错**(最容易被忽略的一条)
   把 apiBase 改成 `https://example.com`。预期:窗口照常打开,走缓存或桌面池;
   **检查 `cached-account.json` 没有被写成 `{}`**;重启一次确认缓存没被污染。

9. **重入 + 池子不被抽干**
   `Cmd+W` 关窗,快速连点两次 Dock 图标。预期:只开出 1 个窗口,后台活跃租约数 = 1。
   再重复「关窗 → 重开」3 轮,后台仍应是 1 而不是 4。
   断网状态下再重复一次,确认 Dock 依然能开出窗口(守卫没卡死)。

10. **回滚路径**
    删掉 `server-config.json`。预期:完全退回第 1 条的纯本地行为。
    这是应急出口,务必确认可用。

11. **(可选,耗时)长运行续租**
    挂 35 分钟以上。预期:后台能看到 `expires_at` 被推后,页面不掉登录;
    后台手动回收租约后,当前窗口不受影响(下次启动才重新租)。
